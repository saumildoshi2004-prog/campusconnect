About CampusConnect

Web Technology Mini-Project for Indus University • Computer Engineering Department

Project Overview

CampusConnect is a modern student activity and event management platform developed for Indus University. Its primary focus is CESA (Computer Engineering Students Association), while providing distinct portals for university guest seminars and general campus fests.

Core Architectural Principles

  • 1. Dedicated CESA Portal: CESA competitions, hackathons, committee members, and departmental activities are hosted exclusively on their own landing page.
  • 2. Independent Seminars: Expert lectures, placement roadmaps, and research talks feature an explicit "Organized by" badge.
  • 3. Comprehensive Tech Stack Integration: Built adhering to academic syllabus rubrics: HTML, CSS, JavaScript, AngularJS 1.8, PHP, and MySQL SQL Database.
  • 4. Dual Data Resilience: Automatically communicates with the PHP MySQL backend when connected to a local server (like XAMPP), while gracefully operating via browser LocalStorage when opened statically.

Technologies Employed

HTML5 & CSS3

Semantic responsive layout, custom modern theme, glassmorphic navbar, poster overlays, dark mode toggle.

JavaScript (Vanilla)

Interactive calendar, toast alert system, registration modals, PDF pass rendering, local storage sync.

AngularJS 1.8

Interactive Event Explorer with two-way data binding (ng-model), dynamic filters, reactive seat counter, form validation.

PHP & MySQL Database

RESTful PHP API with PDO prepared statements, student/admin authentication, ticket issuance, relational schema with 8 tables.
