How to Upload and Run the SQL Database

Method 1: 1-Click Browser Auto Setup (Easiest)
Recommended

If XAMPP is running, you can set up the complete database and import all seed records in a single click without opening phpMyAdmin:

  1. Start Apache and MySQL in the XAMPP Control Panel.
  2. Click the button below or visit http://localhost/campusconnect/api/setup_db.php:
Open 1-Click Database Setup (setup_db.php)
Method 2: Upload via phpMyAdmin (Standard University Method)

Follow these simple steps in phpMyAdmin:

  1. Open your browser and navigate to http://localhost/phpmyadmin.
  2. Click on "New" (or "Databases") in the left sidebar.
  3. Enter database name: campusconnect, select collation utf8mb4_unicode_ci, and click "Create".
  4. Click on the newly created campusconnect database in the sidebar.
  5. Click on the "Import" tab at the top menu bar.
  6. Click "Choose File" (Browse) and select database.sql from your project directory:
    c:\Users\saumi\Downloads\CampusConnect\campusconnect\database.sql
  7. Scroll to the bottom and click the "Import" (or "Go") button.
  8. You will see a green success message: "Import has been successfully finished, queries executed."
Method 3: Upload via XAMPP Shell / Command Prompt

If you prefer running a command in Windows Terminal or XAMPP Shell:

# Run this inside the campusconnect directory in PowerShell:
& "C:\xampp\mysql\bin\mysql.exe" -u root -e "CREATE DATABASE IF NOT EXISTS campusconnect;"
& "C:\xampp\mysql\bin\mysql.exe" -u root campusconnect < database.sql
Running CampusConnect on Localhost

To run the full stack with PHP & MySQL working together:

  1. Copy the campusconnect folder to C:\xampp\htdocs\campusconnect.
  2. Open your browser and navigate to:
    http://localhost/campusconnect/public/index.html
  3. All PHP APIs and the MySQL database will connect automatically!
